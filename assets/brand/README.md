# dedo brand

Each mark comes in a light and a dark version; the dark one is for dark backgrounds.

| File | Use |
| --- | --- |
| `readme-banner-light.svg`, `readme-banner-dark.svg` | The README header; it follows the reader's GitHub theme. PNGs at 2560×640 for elsewhere. |
| `social-preview.png` (and `.svg`) | The repository's social preview, 1280×640: Settings → General → Social preview. |
| `dedo-avatar.png` (and `.svg`) | An organisation or repository avatar, 512×512. |
| `dedo-logo-light.svg`, `dedo-logo-dark.svg` | The mark with the name, for documents and slides. PNGs too. |
| `dedo-mark-light.svg`, `dedo-mark-dark.svg` | The mark alone, such as a favicon or an icon. PNGs at 512×512. |
| `dedo-mark-mono-light.svg`, `dedo-mark-mono-dark.svg` | The mark in one colour, for print or where colour does not fit. |
